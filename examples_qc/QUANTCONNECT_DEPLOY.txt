BASELINES (pick one via ACTIVE_BASELINE at top of main.py)
--------------------------------------------------------------------------------
  maximize        — ~60x / ~91% CAGR / ~45% max DD (same-bar, rails off)
  institutional   — lower-DD research (EOD, ~25% vol, ladder, regime score)

UPLOAD — ONE FILE ONLY
--------------------------------------------------------------------------------
  conditional_sector_rotation_improved.py  →  rename to  main.py

Do NOT upload csr_profiles.py for single-file baselines (no import in main).

File size must stay under QuantConnect 64k limit.

Hardcoded toggles at top of main.py:
  USE_QC_UI_PARAMETERS = False
  ACTIVE_BASELINE = "institutional"   # or "maximize"

Expected logs:
  ACTIVE_BASELINE=institutional ... INSTITUTIONAL profile: EOD, rails on ...
  ACTIVE_BASELINE=maximize ... MAXIMIZE_BACKTEST_EQUITY profile: same-bar ...

QuantConnect parameter panel (optional)
--------------------------------------------------------------------------------
Set USE_QC_UI_PARAMETERS = True and use research_preset:

  research_preset=institutional   — same as ACTIVE_BASELINE=institutional
  research_preset=production      — EOD + rails, no ladder/regime score
  research_preset=maximize          — headline equity maximization
  research_preset=realistic         — adds default slippage 0.001/share

Key institutional parameters (override in QC panel when USE_QC_UI_PARAMETERS=True):
  regime_mode=spy_and_qqq
  regime_score_min_bull=0.55
  regime_hysteresis_days=3
  bull_ladder_tqqq_min=0.65
  bull_ladder_qld_min=0.40
  target_ann_vol=0.25
  target_ann_vol_bull=0.28
  target_ann_vol_bear=0.18
  max_drawdown_pct=0.28
  bull_tqqq_momentum_days=15
  use_vix_delever=true
  vix_delever_ratio=1.20
  vix_delever_mult=0.55
